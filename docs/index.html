From question to rule

The CCB keeps the decision human-readable.

People start with a short proposal. The board discusses it in GitHub. Only an accepted decision becomes part of the versioned profile that technical repositories consume.

  1. 01ProposeDescribe the change in plain language.
  2. 02DiscussCountries and implementers add evidence.
  3. 03DecideCCB records an accepted or deferred outcome.
